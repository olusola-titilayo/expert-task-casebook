**NPV is about $329.83, using the mid-year convention.**

The cash arrives evenly through each year, so on average it arrives half-way through. Year 1 is discounted 0.5 years, year 2 is discounted 1.5 years, and so on:

NPV = -1,000 + 400/1.10^0.5 + 400/1.10^1.5 + 400/1.10^2.5 + 400/1.10^3.5 = **$329.83**

The standard year-end formula gives $267.95, which assumes each year's money arrives on the last day. That understates value by $61.89, about 19% of the true NPV. The size of the gap is the point: the choice of convention isn't a rounding detail. It would rarely flip this decision, but it could flip a closer one.

Assumption to confirm: billing is level through the year, with no seasonality.
